# 🧪 Electron Frontend - Experimental

**Status:** Em desenvolvimento  
**Não recomendado para uso em produção**

## Sobre

Esta é uma versão experimental do AI Copilot com frontend Electron separado do backend Python.

## Problemas Conhecidos

- Event loop threading issues no backend
- WebSocket pode desconectar
- Performance inferior à versão PyQt6
- UI pode não mostrar transcrições corretamente

## Como Usar

Veja `README.md` na raiz do projeto.

**Use a versão PyQt6 (`src/main.py`) para trabalho real!**
