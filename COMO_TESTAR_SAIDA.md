# Como Identificar o Dispositivo de Saída Correto

## Problema
Você precisa saber qual dispositivo de saída capturar para gravar áudio do sistema (apps, música, etc).

## Solução: Botão de Teste

### Passo a Passo

1. **Abra Configurações** (⚙️)

2. **Clique em "🔄 Atualizar"** para carregar dispositivos

3. **Selecione um dispositivo** na lista "Dispositivo de Saída"
   - Ex: "Microsoft Sound Mapper - Output"
   - Ex: "Alto-falantes (Realtek Audio)"
   - Ex: "Headphones"

4. **Clique "🔊 Testar"**
   - Um beep será tocado
   - Vai aparecer um alerta

5. **Você OUVIU o beep?**
   - ✅ **SIM** → Este é o dispositivo correto!
   - ❌ **NÃO** → Selecione outro dispositivo e teste novamente

6. **Quando encontrar o correto:**
   - ☑ Marque "Ativar captura de áudio da saída selecionada"
   - Clique "Salvar Configurações"

## Dispositivos Comuns

- **Microsoft Sound Mapper** - Saída padrão do Windows
- **Alto-falantes** - Caixas de som do PC
- **Headphones** - Fone de ouvido
- **Monitor Audio** - Áudio do monitor
- **HDMI Output** - Saída HDMI (TV)

## Dica

O dispositivo que você OUVE normalmente é o que deve selecionar!
